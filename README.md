Letras y Aromas

Tienda virtual de libros y velas artesanales construida con **React + Vite**.

## Descripción

Una página web que permite explorar y comprar libros y velas con aromas especiales. La tienda se divide en categorías principales: libros y velas, con funcionalidades de filtrado y carrito de compras.

## Características

- **Catálogo interactivo** de libros y velas con filtrado por tipo
- **Carrito de compras** con gestión de estado local
- **Navegación intuitiva** con React Router
- **Diseño responsive** con componentes UI  estilizados
- **Animaciones y efectos** visuales atractivos

## Estructura de Páginas

- **Home** - Página principal con sección de beneficios y productos destacados
- **Catalogo** - Catálogo completo con filtrado por tipo (libros, velas, todos)
- **Nosotros** - Información sobre la tienda y su filosofía
- **Admin** - Panel de administración

## Componentes Principales

- `Navbar` - Barra de navegación superior
- `Footer` - Pie de página
- `ProductCard` / `ProductList` - Componentes de exhibición de productos
- `ModalCarrito`, `ModalLogin`, `ModalRegistro` - Modales de interacción
- `Filters` - Componentes de filtrado

## Hooks

- `useProductos` - Gestión de productos y estado del carrito

## Tecnologías

- **React 18** con Vite 5
- **React Router DOM** para enrutamiento
- **CSS personalizado** con clases utilitarias
